# RakshaNet Final Project Checklist

## Working in this package
- Existing UI retained as the project baseline
- Node/Express backend
- Supabase/PostgreSQL integration hooks
- ONNX landslide inference
- Unified intelligence API
- ML risk grid
- Route risk assessment
- Contextual terrain + historical signals
- Satellite observation layer
- Assam telemetry source layer
- Localized alert generation
- Offline emergency report queue
- Service-worker app-shell caching
- Project syntax/preflight validation

## Not falsely claimed
- No direct sensor data is claimed as trained model input unless the model artifact actually contains it.
- Satellite imagery is not represented as a numerical ML feature without a processing pipeline.
- Composite risk score is not called a probability.
- AI predictions are not presented as official government warnings.
